# Minecraft AFK Client v3 (mc-afk-mesajli)

Minecraft AFK Bot Yöneticisi ve Akıllı Yanıt Sistemi - Hugging Face Repository: `Sunay-Seyidli/mc-afk-mesajli`

## Özellikler
- **Doğal İnsansı Anti-AFK**: S-Curve Cosine interpolasyonlu bakış ve mikro adımlama.
- **Akıllı Türkçe Chat & Fısıltı Yanıtlayıcı**: Otomatik mesaj algılama ve insansı gecikmeli cevaplar.
- **Bot Takip Sistemi**: Pathfinder ile oyuncuları akıcı ve engelsiz takip etme.
- **Çoklu Sürüm ve Sunucu Desteği**: Java 1.8'den Java 25 snapshotlarına kadar geniş sürüm seçeneği.
- **Görsel Envanter ve Kontrol Paneli**: Bot yönetimi, canlı konum, can/açlık ve script çalıştırma.
